MISSION 02

Console Input & Output

Console I/O allows a Java program to interact directly with the user through the keyboard and screen.

⚔ Reading Input with Scanner

The Scanner class is one of the simplest ways to read input from the keyboard.

nextInt() Reads an integer
nextDouble() Reads a decimal value
next() Reads one word
nextLine() Reads an entire line
nextBoolean() Reads true or false
JAVA • CONSOLE INPUT 
import java.util.Scanner;

public class ConsoleInput {
    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        System.out.print("Enter your name: ");
        String name = sc.nextLine();

        System.out.print("Enter your age: ");
        int age = sc.nextInt();

        System.out.println("\n--- Shinobi Profile ---");
        System.out.println("Name: " + name);
        System.out.println("Age: " + age);

        sc.close();
    }
}
TECHNIQUE

Console Output

Java uses System.out to display information on the console.

System.out.print()

Displays text without moving to a new line.

System.out.print("Hello");

System.out.println()

Displays text and moves the cursor to the next line.

System.out.println("Hello");

System.out.printf()

Displays formatted output.

System.out.printf("Age: %d", age);
MISSION 03

Reading Data from Files

File input allows Java programs to retrieve information stored permanently on a computer.

📜 FileReader

FileReader is used to read character data from a file. It is useful when the program needs to access text files.

📜 BufferedReader

BufferedReader improves reading efficiency by buffering characters and providing the convenient readLine() method.

SHINOBI TIP: BufferedReader is especially useful when reading a file line by line.
JAVA • FILE READING 
import java.io.*;

public class ReadFile {

    public static void main(String[] args) {

        try {

            FileReader file =
                new FileReader("mission.txt");

            BufferedReader reader =
                new BufferedReader(file);

            String line;

            while ((line = reader.readLine()) != null) {
                System.out.println(line);
            }

            reader.close();

        } catch (IOException e) {

            System.out.println(
                "Error reading the file."
            );
        }
    }
}
MISSION 04

Writing Data to Files

File output allows programs to permanently save information.

JAVA • FILE WRITING 
import java.io.*;

public class WriteFile {

    public static void main(String[] args) {

        try {

            FileWriter file =
                new FileWriter("mission.txt");

            BufferedWriter writer =
                new BufferedWriter(file);

            writer.write("Java Shinobi Academy");
            writer.newLine();

            writer.write("File I/O Training Complete!");
            writer.newLine();

            writer.close();

            System.out.println(
                "Data written successfully."
            );

        } catch (IOException e) {

            System.out.println(
                "Error writing the file."
            );
        }
    }
}

✍ FileWriter

FileWriter is used to write character data into a file.

✍ BufferedWriter

BufferedWriter writes text efficiently by using a buffer. It also provides methods such as newLine().

IMPORTANT: Always close the file or use try-with-resources to properly release system resources.

Complete Java Example

This program combines console input with file output.

FINAL MISSION • STUDENT RECORD 
import java.io.*;
import java.util.Scanner;

public class StudentRecord {

    public static void main(String[] args) {

        Scanner sc = new Scanner(System.in);

        System.out.print("Enter student name: ");
        String name = sc.nextLine();

        System.out.print("Enter department: ");
        String department = sc.nextLine();

        System.out.print("Enter mark: ");
        int mark = sc.nextInt();

        try {

            FileWriter fw =
                new FileWriter("student.txt");

            BufferedWriter bw =
                new BufferedWriter(fw);

            bw.write("STUDENT RECORD");
            bw.newLine();

            bw.write("Name: " + name);
            bw.newLine();

            bw.write("Department: " + department);
            bw.newLine();

            bw.write("Mark: " + mark);
            bw.newLine();

            bw.close();

            System.out.println(
                "\nRecord saved successfully!"
            );

        } catch (IOException e) {

            System.out.println(
                "Unable to save the record."
            );
        }

        sc.close();
    }
}
